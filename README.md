# web-development.github.io

Este es el repositorio del sitio web destinado para mostrar los desarrollos web o sistemas de información que podemos desarrollar para tu negocio o empresa.

# Tecnologías Utilizadas

- HTML
- CSS
- JavaScript

# Estructura del Proyecto

El proyecto está dividido en tres secciones:

- **Inicio**: Presentación del proyecto y información general.
- **Servicios**: Descripción de los servicios que ofrecemos.
- **Precios**: Detalles de los precios y características de los servicios.
- **Contacto**: Información de contacto para cualquier duda o consulta.
- **Footer**: Información de contacto y información de licencia.
